# Menú app scaffold

Este PR añade un scaffold para una pequeña app Flask que muestra los menús de los restaurantes.

Cómo ejecutar (local):

1. Crear un entorno virtual (recomendado): python -m venv venv && source venv/bin/activate (Linux/mac) o venv\Scripts\activate (Windows)
2. Instalar dependencias: pip install -r requirements.txt
3. Ejecutar: python app.py
4. Abrir: http://127.0.0.1:5000

Notas:
- Las imágenes usadas en los ejemplos se cargan desde los mockups ya presentes en `Diseño Externo/Mockup` en la rama `main`.
- Si prefieres que copie físicamente los assets dentro de `static/assets/`, puedo hacerlo en un siguiente commit (pero eso duplicará archivos binarios).
